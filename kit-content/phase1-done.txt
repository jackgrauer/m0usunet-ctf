  You found a Jenkins build automation server. Companies compile
  and ship code on these while building a website. They're old and
  famously, catastrophically broken. Normally, this belongs behind
  the corporate VPN. This one isn't. Someone left it out. This is
  our window in.

  Now that we've found our window, we need to climb through. Jenkins
  servers have dozens of known bugs that let remote users -- us --
  control them without logging in. All we need to do now is find a
  known bug specific to this version of the server.

  ─── next ──────────────────────────────────────────────────────────

  We'll use nikto to fingerprint the host and learn its exact
  version number. nikto is a web vulnerability scanner -- perl,
  small, classic. Point it at a host, it runs thousands of probes
  against known software versions and noisy endpoints. When it
  finds something, it shouts.

  Type each of these three commands in order, one at a time,
  hitting Enter after each:

      1.  cd nikto
      2.  nikto -h http://<the IP you identified above using nmap>:8080/
      3.  cat advisories

  Now we have to find a CVE that does two things at once:

    (a) it has to apply to the EXACT VERSION of Jenkins nikto
        just reported.

    (b) it has to grant us INTERNAL CONTROL of that server
        without us having to log in -- because we don't have
        credentials. Anything requiring a login is useless to us.
        Anything that's just info disclosure or XSS gets us
        information but no way to actually run commands.

  Lining up (a) and (b) means we have a known, public exploit
  that turns our outside view of the box into a shell on the
  inside. That's the door.

  A CVE (Common Vulnerabilities and Exposures) is just a public
  catalog number for a known software bug. Every serious bug gets
  one -- CVE-YYYY-NNNNNN -- and the catalog records what software
  it affects, what versions, what kind of attack it enables, and
  whether it needs login credentials.

  Only one row in the advisories table fits both (a) and (b).

  When you find it, type the CVE id at the prompt and hit Enter.

  Stuck?  cat hint  -- no penalty.
