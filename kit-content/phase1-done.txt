  You found a Jenkins build automation server. Companies compile
  and ship code on these while building a website. They're old and
  famously, catastrophically broken. Normally, this belongs behind
  the corporate VPN. This one isn't. Someone left it out. This is
  our window in.

  Now that we've found our window, we need to climb through. Jenkins
  servers have dozens of known bugs that let remote users — us —
  control them without logging in. All we need to do now is find a
  known bug specific to this version of the server.

  ─── next ──────────────────────────────────────────────────────────

  We'll use nikto to fingerprint the host and learn its version.
  Nikto is a web vulnerability scanner — perl, small, classic. You
  point it at a host and it runs thousands of probes against known
  software versions, dangerous endpoints, misconfigurations, default
  credentials. When it finds something, it shouts.

  Type each of these three commands in order, one at a time, hitting
  Enter after each. The first one moves you into the right folder;
  the second runs the scan; the third shows you the CVE table.

      1.  cd /mnt/kit/02_nikto
      2.  nikto -h http://<the IP you just identified>:8080/
      3.  cat advisories

  Then type the CVE id straight at the prompt and hit Enter.
  Stuck?  cat hint  — no penalty.
