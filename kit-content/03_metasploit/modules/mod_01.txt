NAME      auxiliary/scanner/http/tomcat_mgr_login
CVE       n/a
TARGETS   Apache Tomcat Manager 5.5-9.x
RANK      Normal
AUTH      brute force
TYPE      auxiliary / login

DESCRIPTION
  Attempts to login to Apache Tomcat's /manager/html interface with
  a wordlist of default and weak credentials. Not an exploit on its
  own — pairs with tomcat_mgr_upload once valid credentials are found.

OPTIONS
  RHOSTS      (required) target host(s)
  RPORT       (required) target port (default 8080)
  USER_FILE   (optional) username wordlist
  PASS_FILE   (optional) password wordlist
